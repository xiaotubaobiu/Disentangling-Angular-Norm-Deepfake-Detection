## 保持不变的科学设置

三个骨干全参数微调，训练输出不增加L2，特征接二分类头。学习率CLIP1e-5、DINOv2 5e-5、EfficientNet1e-4；每卡实际batch128、AdamW/CE/WD5e-4、AMP、梯度裁剪1、EMA0.999。warmup1是会议版epoch公式：第1轮即base LR，第2轮位于余弦起点，其后衰减。

开发seed为1007/1042。D在源DEV与隔离CDF-DEV上开发总预算，正式五seed轨迹只按源DEV选点；已冻结CLIP2、DINOv2 30、EfficientNet2轮。H只看源DEV，以共同DEV-B上B/AB两模型AUC平均值选择共同epoch、共同patience5；已冻结CLIP10、EfficientNet15、DINOv2 60轮。改变cosine总预算需重新初始化，保留对应真实训练和比较证据。

H-DINO两条从头60轮开发实际结束48/60轮、共同最佳43/57轮，共同DEV-B平均AUC76.9296%，高于从头30轮的73.4509%。全部抽样、更新事件、最佳EMA及原子恢复state已核验，原生TRAIN/DEV评价确认模型确有学习，同时源训练—验证差距明显。第二seed到上限时连续3轮未改善，未触发patience5；这是经源证据审阅的有限预算，不是全局最优或统计收敛保证。正式三对保持会议学习率5e-5和其他参数，未使用CDF/DFD选点。证据为产物`operations/H_dino_cap60_source_budget_assessment.json`及`H_dino_cap60_formal_freeze_acceptance.json`。

源域最佳权重不一定接近CDF开发最佳权重。D-DINO seed1007为第22轮对第5轮，相应CDF开发AUC80.1310%与82.4286%；seed1042为第20轮对第1轮，相应72.6429%与81.5357%。CLIP/EfficientNet最终2轮窗口的差距只有0–1轮，但较长参考中也出现CLIP第4对第8轮、EfficientNet第7对第2轮。全部12条已完成开发轨迹及首次源patience停止回放见产物`reports/development_model_selection/source_vs_cdf_development_epochs.csv`；这些是开发集择优描述，不是正式测试成绩，不改变已冻结的正式选点规则。

EMA平滑可训练参数；BN等buffer使用当轮live值，与会议原实现一致。AMP跳过参数更新时不更新EMA。每轮EMA在源DEV计算正确自然视频mean-probability pooled AUC；严格提高保存最佳，连续5轮不提高早停。`state.pt`支持恢复raw模型、优化器、scaler、EMA、随机状态、早停计数和最佳EMA；`best_model.pth`用于全部评价，不用末轮权重代替。

DF40增强完整保留官方顺序与概率，之后使用对应预训练输入归一化。DINOv2使用官方实现与权重；位置插值在CPU执行，值与梯度保持官方公式，避免严格确定性模式下的CUDA bicubic backward问题。

数据采样为每自然视频按数值帧序选8个不同RGB帧，训练规范输入合并相同RGB并保存全部方法采样贡献。real总概率.5，每个fake方法.5/21，有放回抽样；实际epoch数量不保证完全相等。源官方train的360对按固定seed20261023拆为306 TRAIN/54 DEV。

源TRAIN每轮抽102,272次，为799个完整batch。规范输入的代表video UID数量不同于自然训练关联数，训练规模使用`training_associations.parquet`。

CDF开发隔离采用完整候选的已知来源、精确RGB、跨方法同名和保守身份名称代理传递闭包；共隔离890个候选，实际打分440个，450个未打分关联视频也不回流。DEV与正式排序、CAL、TEST的视频、联合关系组和选中RGB交集均为0；CAL和阈值TEST也为0。未知来源祖先不作独立性认证。target_full包含64个CAL真实视频，RQ4只在另列93真TEST上报告阈值效果。

D预算开发使用过CDF-DEV真/假标签，论文须披露目标信息使用。正式训练仅按源DEV选最佳EMA。保守闭包使CDF固定TEST只有1个联合组，受影响组bootstrap区间为NA，保留点估计和训练seed样本SD。

八格=正确/错误分组×Raw/L2×mean-logit/mean-probability。错误键为`domain,label,video_id`，把多个方法各8帧合并，k方法为8k帧；源假单位2,884→280，CDF假单位12,037→1,830，真实单位不变。正常分组分别报告21方法macro和pooled AUC，混合方法的错误组macro为NA。

阈值分析包括默认阈值、源真实CAL经验5% FPR阈值、目标真实CAL的10/20/40个样本各200次子集校准，主预算20，80因CAL仅64而NA。全部阈值使用同一固定TEST，子集波动与训练seed波动分开。TEST最优阈值仅作诊断。原FP32帧特征、原头、mean-logit尺度负控及mean-prob高精度复算用于数值审计；分组结论反转本身不证明Sigmoid饱和。

## H数据和预处理

H使用FF++ c23的1,000真实＋四方法各1,000伪造原视频，DFD c23的363真＋3,068假为跨域候选。固定32个时间候选，先选8个不同RGB母帧再运行处理，失败不补帧。A采用公开`biubug6/Pytorch_Retinaface` MobileNet .25的5点检测和ArcFace模板对齐336；B使用dlib HOG/SVM＋68点、chip几何、padding .25及OpenCV bicubic渲染224。AB在保存的A.png上重新完整运行B。保留图像、mask、母帧索引/PTS和失败原因，模型输入仅RGB。

共同训练2,951视频、23,608母帧，共同DEV525视频；每轮抽23,680次，为185个batch。B/AB共享初始化、抽样、增强及模型RNG。真实概率.5，四伪造方法各.125。全部B和共同队列分开：FF源TEST为697/700和679/700，DFD为2,139/3,431和1,361/3,431。覆盖率按类别记录，AUC解释为成功子集的条件表现。

M1在B训练，M2在AB训练；四格为M1→B、M1→AB、M2→B、M2→AB。部署主比较使用全部B队列的M2−M1，共同队列分析失配和交互。H不使用CDF或DFD选点或校准，阈值仅由源真实CAL确定。

## 清理后如何使用

原始数据默认保留于 `/Dataset/deepfake_detection/DF40_all`。此前的大型清单、audit sqlite、缓存、权重、预测和派生图像已按用户要求清理；这套代码不读取那些旧运行目录。

`configs/data_protocol/`保留42份官方索引SHA256、官方来源划分、源CAL候选和CDF开发策略等定义，不包含图片、权重或预测。CDF原80/97真实ID划分属于基础来源记录，当前角色由完整候选审计和开发关联隔离后重建为64/93，实际以本轮冻结清单为准。

独立Python环境在本机 `/home/z/.venvs/deepfake-journal`。如在新机器运行，可依据根目录 `requirements.lock.txt` 建独立Python3.11环境。不要把旧环境的绝对路径作为项目依赖。

```bash
# 可随时执行：只查询，不创建实验输出或加载模型
python run.py status
python run.py --help
python -m pytest tests -q

# 新输出根的数据准备模板；会全量读取原始图像
python run.py prepare --output-root /home/z/workspace/journal_21methods
```

默认输出为仓库下被Git忽略的 `outputs/journal_21methods/`。若prepare使用了自定义output-root，后续所有命令都需传同一值。

三份初始化文件的官方URL、SHA256及目标路径见 `configs/journal.json`。prepare不需要权重；训练前按配置下载至 `weights/` 并核验SHA256。数据准备不隐式下载权重，也不训练。

```bash
# GPU_UUID 必须取configs中0–3之一，且该GPU空闲
CUDA_VISIBLE_DEVICES=GPU_UUID python run.py train --run-id D_formal_clip_vit_b16_seed7 --output-root /home/z/workspace/journal_21methods
CUDA_VISIBLE_DEVICES=GPU_UUID python run.py extract --run-id D_formal_clip_vit_b16_seed7 --output-root /home/z/workspace/journal_21methods
python run.py analyze --run-id D_formal_clip_vit_b16_seed7 --output-root /home/z/workspace/journal_21methods
python run.py summarize --backbone clip_vit_b16 --output-root /home/z/workspace/journal_21methods
```

以上`run.py`命令对应基础模板。当前实际实验须使用下节本轮配置入口。训练和缓存均有独占锁；实际AMP batch128以及连续/恢复训练的模型、AdamW、scaler、EMA、RNG一致性已通过真实GPU资格检查。
