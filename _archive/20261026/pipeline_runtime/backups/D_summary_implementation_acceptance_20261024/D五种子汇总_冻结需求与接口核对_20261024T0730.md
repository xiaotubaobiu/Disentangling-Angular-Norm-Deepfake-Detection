# D五种子汇总：冻结需求与现有接口核对

此文件只核对最新冻结计划第7–9节与当前代码接口，不包含正式检测结果，也不表示最终五种子汇总入口已经实现。五种子固定为7、42、123、2026、3407；三骨干分别报告。开发种子1007/1042不能升格或混入。

## 统计口径

主表保留逐seed结果及五seed均值±样本SD（ddof=1）。先在同seed内计算L2−Raw、collision−correct交互以及目标真实n20阈值相对源阈值的变化，再汇总相同对照；不能跨seed拼成一个ROC，也不能把15骨干模型作为IID总体。200个CAL子集、2000个TEST重采样和五个训练模型属于不同层次。逐比较区间是对冻结模型、来源/代理分组、CAL池及保存子集条件化的pointwise区间，不能直接平均各seed区间端点冒充一个新置信区间。

RQ2主比较为CDF-full正确分组mean-logit的L2−Raw；RQ3分别对两聚合报告分组×L2交互。每seed反转按两delta符号及1e-10容差判断，五seed反转计数与全体平均反转分开。RQ4在独立的固定TARGET_TEST池上报告n20相对源阈值的FPR/TPR/pooled BA，其余10/20/40/80预算全部保留，不能借用CDF-full AUC或旧macro BA。

## 已有接口与最终装配缺口

`scoring_d.d_effects` 已产生每seed delta_correct、delta_collision、interaction、reversal与valid；`summarize_seed_effects` 已提供样本SD、n_valid_seeds、complete_five_seeds、n_seed_reversals和mean_reversal。本轮四类合成接口探测通过，包含一个seed反转而平均未反转、缺一个seed、一个数值NA、重复seed拒绝。该探测不使用真实模型分数，不能作为实验结果。

该底层函数在complete_five_seeds=false时仍会计算有效子集的描述性均值。因此最终主表入口必须读取完整性标记和实际种子集合，不能将四个有效seed的均值标成完整五seed结果；逐seed NA、失效原因和n_valid须保留。这里是汇总使用边界核对，没有修改运行中代码或扩大测试/阈值选择规则。

当前`analysis_d`仅处理单个正式模型。最终跨文件入口仍须实现并独立验收：只接受登记骨干的五个正式seed，校验全部七角色缓存及analysis complete身份/hash；拒绝开发、历史、重复、缺失、部分或被改写工件。不能只凭status命令的marker计数判定分析可用，不能在尚无缓存时生成空表并标作完成。
