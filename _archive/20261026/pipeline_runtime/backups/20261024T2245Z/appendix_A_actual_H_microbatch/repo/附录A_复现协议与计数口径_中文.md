# 附录A：复现协议与计数口径

*期刊补充材料准备稿；本文只说明已冻结协议及工件身份，不包含未完成模型的性能结果。各模型最终成功更新数、完整结果表及公开归档信息仍须在实验完成后核验。*

## A.1 视频、RGB输入与抽样预算

自然视频身份包含数据集、域、方法与视频ID。真实视频的方法标签统一为real，在负样本池只计一次。来源组表达已知或代理祖先关系，不能用视频UID或人物身份代替；精确RGB连接只约束已观察的内容重复。计分时的八帧自然视频与训练时的RGB规范输入是不同层级。

D的TRAIN含611个真实和12,232个伪造视频，共12,843个视频、102,744条八帧关联。在493个跨方法RGB组内合并519条冗余关联，得到102,225个规范RGB输入；合并保留各方法贡献的采样质量。真实来源281的缺失解释了611与名义612的差别，不以复制图像补齐。每轮按冻结质量有放回抽样，将总抽样预算向128的倍数上取整为102,272条。多出的47是总预算取整差额，不能解释为固定追加47幅新图像，也不能把102,272当作唯一RGB数。

H的两个训练历史使用相同的3,053个共同合格自然视频和24,424个逻辑母帧槽位。B与AB是同一母帧的两种输入历史，不把两版本或有效区域mask计作额外自然视频。每个模型的有放回抽样预算为24,448条，多出的24同样来自预算取整。资格失败不会通过另一历史的图像或未选帧补齐。SOURCE_UNUSED只参与完整关系/RGB图，始终不进入训练、开发、校准和测试。

## A.2 尝试、成功更新与精度

有效批量固定为128。D已资格通过的microbatch为32，以梯度累积保持该有效批量；H的microbatch须由实际源域GPU资格冻结，不能从CPU测试或数据冻结推定。D与H每轮分别有799和191次优化尝试，基础30轮分别为23,970和5,730次。任何登记的延长轮数均按实际冻结轮数计算总预算。

设A为尝试数、S为AMP跳步数，成功优化器更新数为U=A−S。学习率时钟依尝试推进，Adam状态只随成功更新推进。有限loss但非有限梯度按冻结的scaler与停止规则处理；逐项保留事件、后续恢复和累计计数，不补步、改种子、重选阈值或修改测试池来消除差额。最终表须分别报告A、U、S，不能用轮数证明成功更新完全相同。H若触发登记的统一FP32回退，仅使用注册为有效的成对模型生成最终缓存，原AMP工件保留而不混用。

## A.3 工件绑定与独立复算

每个run保留源TRAIN/DEV清单哈希、配置、初始化权重、环境锁、资格及训练代码身份，以及种子、逐轮抽样/增强记录、优化器、RNG、scaler和恢复点。主终点为冻结最后轮；源域最佳权重单独保存，仅作登记敏感性比较，不能按目标结果替换主权重。

正式推理的七个角色缓存分别绑定自身清单与同一原始FP32分类头。头的行与偏置先提升至FP64再作差；排序使用登记的精度规则，操作点继续使用固定FP64阈值空间。保存后重新读取分数，独立复算AUC与整数操作计数。CDF-full与校准分析自身固定TEST不同，CAL分数不能计入TEST AUC。H的all-B与共同队列也分别保留估计对象及阈值来源。

五个训练种子、200个校准子集和2,000次测试bootstrap保持独立的变异口径。未解决的数值排序、缺失方法、不可用预算或不足的连通闭包保留NA及原因，不删除不利种子后补算。清单与版本的机器可读身份见随附复现资产索引；这些身份支持复算，不认证未记录的生成祖先，也不构成总体误报保证。
