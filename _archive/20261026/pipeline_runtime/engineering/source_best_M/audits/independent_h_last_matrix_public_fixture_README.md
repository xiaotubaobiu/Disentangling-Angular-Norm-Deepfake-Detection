# Independent matrix public fixture (reviewed e751 contract)

The generator is preserved in independent_h_last_matrix_public_fixture.py; the reviewed source is archived as h_last_matrix_result_audit_reviewed_e75127e3.py. Default output always goes to a fresh/tmp directory. Set H_MATRIX_REVIEW_TMP to a chosen/tmp directory and optionally H_MATRIX_REVIEW_SOURCE to a new SHA-reviewed wrapper to test it. The v1 generator targets the initial e751 binding contract; new mandatory proof roles added by a fix may require fixture adaptation.

Run with R/environment/bin/python, empty CUDA, OMP/MKL/OPENBLAS_NUM_THREADS=1 and PYTHONDONTWRITEBYTECODE=1. It never accesses real P, existing saved-score/weight/image files or actual CPU-slot files. It reads only accepted code bytes to stage exact code-copy proof fixtures, then redirects literal root anchors in an isolated module to a temporary surrogate root. The real public loaders/proof validators/numeric kernel are not mocked out. Tiny natural-video cohorts have fewer than20 groups; point metric/CAL/effect/NA paths and8cohort routing run, while conditional bootstrap is correctly unavailable. This supplements, not replaces, existing kernel2000draw tests or any actual pair acceptance.

Baseline and three intentionally invalid proof graphs all returned PASS under e751, reproducing the review findings. public_path_probes separately verified externalSHA, root/namespace/seed/symlink and prior-output guards. Review JSON and Q auxiliary notes give exact line references and real field shapes for a scoped fix. No implementation file was edited by this reviewer.
